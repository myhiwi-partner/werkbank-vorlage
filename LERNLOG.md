# Lernlog

Hier schreibst du nach jeder Arbeitssitzung ein paar Zeilen auf. Kurz reicht. Denis und der Coach lesen mit und sehen daran, wo es läuft und wo es hängt. Keine Namen von Betrieben aus deinen Listen, keine Telefonnummern, keine Kundendaten: nur was du gelernt hast.

## Stufen

| Stufe | Was dazugehört | Allein wiederholt am |
|---|---|---|
| 1 Werkzeug | deine KI, Repo, Markdown, Commit und Push | |
| 2 Skills benutzen | Briefing, Nachbereitung, Gespräch vorbereiten, Abschluss | |
| 3 Eigene Skills schreiben | erster eigener Skill | |
| 4 Mit Kundendaten arbeiten | kommt später je Person, Denis schaltet frei | gesperrt |

Eine Stufe ist geschafft, wenn du sie einmal ganz ohne Hilfe wiederholt hast. Dann trägst du das Datum ein. Deine Meilensteine im Vertriebsstrang trägt die KI mit dir in `werkbank.json` ein.

## Acht Kompetenzen

Das Ziel hinter den Stufen: eine eigene KI-Agentur führen können. Beide Lernenden haben denselben Maßstab. Eine Kompetenz zählt, wenn du sie an einem echten Fall gezeigt **und** auf einen zweiten ähnlichen Fall übertragen hast. Übertragen heißt: Du hast den Schritt selbst geführt und nur gezielt Hilfe geholt. Alles selbst machen musst du dafür nicht; KI und Fachleute richtig einsetzen gehört dazu.

| Kompetenz | Du kannst | Gezeigt an (Fall, Datum) | Übertragen am |
|---|---|---|---|
| 1 Eigene Werkbank bedienen | Werkzeuge, Dateien und Zugänge handhaben, Ergebnisse wiederfindbar ablegen | | |
| 2 Mit KI selbständig weiterkommen | Ziel erklären, nächste Schritte finden, bei Hindernissen eine präzise Hilfsanfrage stellen | | |
| 3 Bedarf in ein begrenztes Angebot übersetzen | Ergebnis, Umfang, Preis und Grenzen passend zum Bedarf erklären | | |
| 4 Kunden gewinnen | Bedarf erkennen, Gespräch führen, Wert erklären, nächsten Schritt vereinbaren | | |
| 5 Aufträge organisieren und liefern | Brauchbare Tickets schreiben, Abhängigkeiten sehen, KI und Partner einsetzen, Kunden informieren | | |
| 6 Ergebnisse beurteilen | Ergebnis am Zweck prüfen, Mängel erklären, Fachprüfung richtig einholen | | |
| 7 Wirtschaftlich arbeiten | Erlöse, Werkzeuge, Fremdleistungen und eigene Zeit gegenüberstellen | | |
| 8 Kunden betreuen und weiterlernen | Änderungen und Probleme einordnen, nächsten Schritt organisieren, Erkenntnis festhalten | | |

Welcher Schritt eines Falls welche Kompetenz zeigt, steht im Lernfall unter `wissen/lernfaelle/`. Beträge gehören nicht hierher, die Rechnung zu Kompetenz 7 liegt in deinem Drive-Ordner.
